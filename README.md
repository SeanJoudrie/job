# job

A personal job scanner. Rules you write and can read, instead of a feed that
decides what you're allowed to see.

**[SPEC.md](SPEC.md)** — how the tool works.
**[PROFILE.md](PROFILE.md)** — what it is working from.

Nothing is built yet.

Cover letters, tailored resumes, the applied log and any API key stay on the
device. Scoring and letter-writing run in the browser, so none of it reaches the
scheduled scan.
